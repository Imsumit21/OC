Frederick asked me to build out the live-ops and push calendar for the Zombie Match 3D beta — the four buy weeks that start Monday the 6th. The working rules for how he wants it built are in the brief he shared with me.

Can you put the calendar together in my live-ops calendar sheet? For each beat a player can see across those weeks, work out the windows it runs in, whether it's held and until when, the push that goes with it, and what still has to land before it runs and who owns that. Do the push plan the same way — for each beta push, whether it goes out or waits, and if it waits, what's missing.

If a beat can't run yet, leave a note on its ticket so the owner picks it up. Once the sheet's done, link it on the calendar ticket and send Frederick your recommendation with the trade-offs.
