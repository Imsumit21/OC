# 01b Red-team review (reviewer A): rb-winddown-closeout design

**Summary.** I checked every register row in `truth.json` / `accounts.json` against the seeded wording in `planned_text.json` and the read-only base exports: the HG Costs tab grid in `gsheets/data.json`, #winddown `C0ADGSZKR3R/2026-02.json`, Robert's Gmail threads, Trello, Confluence and GitHub. The biggest problem is the **cost source**. The design's "Dec-25 column" values are the **Dec-26 forecast column** of HG Costs. In the real Dec-25 column (the one that ties to the P&L tab's Dec-25 subtotals), nine rows have different costs, and both totals change. The cell headers are stored as broken date strings, so either column can be argued to be "Dec-25". That makes the cost column, and both totals, two-answer. Several seeded receipts also contradict base mail: the SVB card is a MasterCard in base but every receipt says "Visa ending 4417"; ElevenLabs is an annual $50 plan in base but seeded as $5 monthly; the base tab shows Figma's annual charge as 1,212, not 1,440; and base mail says Linear is on the paid Standard plan. A few rule edges also allow a second defensible answer: Helpshift's dash, Done-vs-open for "closed" accounts, the Intuit duplicate comment, the Carta status, GitHub in the after-plan total, and the clash list. Chronology mostly holds. One prose error is noted.
