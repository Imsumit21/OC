## 2. Goal principles (for the scenario and prompt brief)
1. **One conclusion.** A single audience call; every other output derives from it or from the same session verdicts.
2. **Don't invite an audit.** Name the note and the workbook, ask for the read and close-out. Rules enter through the note by name. The word "valid" triggers an audit. The note must still clearly be the rule source, or a miss reads as "trust the log".
3. **Require commitment.** One call and a state on every ticket, carried by a seeded record, not a prompt rule. This removes the "unresolved" and with-and-without cushions.
4. **Acted on at once.** Reply to Leonard, message to Brian, close-out writes all land.
5. **No extra deliverables.** Register, memo, reply, ticket states, Brian message. No side tabs or independent sections.
6. **Wrong answer ties out** 60 for 60 across forms, tickets and log, and agrees with the leaders. **Right answer is clear**, with a stated metric, tie band and minimum.
7. **Fewer survivors, independent routes.** No block unlocks another. No deciding record names a tester. Nothing depends on a tool error or a dying agent.
