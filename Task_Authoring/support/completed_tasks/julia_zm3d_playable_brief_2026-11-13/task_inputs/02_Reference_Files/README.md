# Reference files — skipped by default

The default pipeline goes from `/create-injection` straight to
`/create-prompt-writing`. Run `/create-reference-files` only when the owner asks;
do not create attachments or a manifest merely because this template folder exists.

When requested, put the actual upload files here (the same folder goes to both
upload screens). Remove this instructional README from the upload. The manifest
belongs outside this folder at `Working_Files/02_Reference_Files_Manifest.md`.
If the task has no attachment, the upload folder must be empty; this README is
scaffolding, not a reference attachment.
