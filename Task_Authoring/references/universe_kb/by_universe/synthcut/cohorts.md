# Natural cohorts (40–500 records)

> Natural record sets for the cohort spine (Hardness_Mastery §2). 'bulk' says whether a list/batch/search call already returns the per-record surface; only Linear comments (seeded) and unmirrored PR comments/reviews are honest per-record reads. 'hazards_inside' intersects the cohort with coherence_hazards lists - exclude those ids or define the rule.
> Confluence (31 pages, 78 versions, 12 comments) and Contacts (171) are below range; Snowflake row sets collapse to one GROUP BY.
> Generated by `_build/assemble_cohorts.py`; full id lists (when ≤ 500) in `cohorts.json`.

## Per-record surfaces and bulk paths by record kind

| Record kind | Per-record surfaces | Bulk call that returns them | Honest per-record calls |
|---|---|---|---|
| linear_issue | description (truncated in list); comments (linear_list_comments; 0 in base -> seeded only); attachments (linear_get_attachments); parent/relations; state, labels, assignee | linear_list_issues returns state/labels/assignee/parent/relations/description(+truncated flag); NO comments. Only Linear comments are an honest one-call-per-record surface (verified, §6b). | 1 (list_comments) when the seeded fact lives in comments; else ~0 |
| github_pr | title/body/head_ref; conversation comments; reviews; review comments; timeline; commits/files | search/list return title/body/branch/merged_at. Comments and reviews are per PR in GitHub, BUT repos with a Slack mirror (see integrations.json INT-01 for this universe's windows) are sweepable at ~50/page; unmirrored repos are per-PR reads. | unmirrored repo: comments + reviews + timeline ~2-3; mirrored repo: timeline/files/commits only |
| slack_thread | replies | slack_conversations_search_messages returns replies; filter-only search (channel+user) pages everything (verified). Not per-record volume. | 0 against a determined agent; useful only as the A14 behavioural trap |
| gmail_thread | messages; quoted history; attachments | gmail_get_messages_batch collapses N reads; search returns snippets. | 0.2-0.5 (attachments are the only per-item hook) |
| trello_card | desc; comments; checklists; card actions | trello_get_board_actions (comment filter) and trello_get_checklists_on_board are bulk. | 0.2-0.5 |
| gcal_instance | attendees/responses; description (absent in base) | gcal_list_events over a window returns them. | ~0 |
| snowflake_row | row columns; FAILURE_NOTE / NOTES text | one SQL query returns all rows. | 0 |
| doc | body_text | none; gdocs_get_document per doc (search returns titles). | 1 |
